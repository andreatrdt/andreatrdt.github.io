## Deployment

The website is deployed using GitHub Pages.

To update the website:

1. Edit `index.html`.
2. Replace `CV_Andrea_Tarditi.pdf` when updating the CV.
3. Keep the CV filename unchanged to avoid broken links.
4. Commit and push changes to the `main` branch.
5. GitHub Pages will redeploy automatically.

---

## Notes

The website is intentionally built as a single-file static page for simplicity, portability, and fast deployment.

Using `.nojekyll` is recommended to ensure GitHub Pages serves the HTML, CSS, and static files exactly as written.
