Projects

Selected academic and applied work

Hawkes Market-Making

2026 Python Hawkes Processes Stochastic Control

Built and calibrated a bivariate Hawkes model of aggressive buy/sell order flow in limit order books. Formulated an HJB stochastic-control market-making problem under CARA utility, modeling fills and adverse selection via predictable thinning/marking, and validated the resulting quoting policy in historical replay/backtests.

Yield Curve Decomposition

2025 Python Fixed Income PCA

Decomposed yield-curve dynamics via PCA into level, slope, and curvature factors, separating Euro-wide components from country-specific movements.

Strategy Backtesting

2025 Python LOB Replay Market Microstructure

Used historical LOB simulations to derive quoting policies, calibrating either the target spread from mid or the volume/position kept in front at each book level. Translated replay results into deployable rules linking quote aggressiveness to expected fills, adverse selection, and inventory risk.

Portfolio Replica

2025 Python Machine Learning Web App

Deployed a simulated fintech investment platform that uses machine learning to classify investors and recommend tailored passive/active ETF portfolios. Built an interactive questionnaire for suitability prediction and surfaced portfolio risk/TER details.

Multivariate Pricing

2024 Matlab Python NIG

Developed and calibrated multivariate Lévy models (NIG) for S&P 500 and EURO STOXX 50. Priced exotic derivatives and compared model performance against VG and Black models.

Energy Price Modeling

2024 Matlab Stochastic Processes Monte Carlo

Modeled electricity futures using OU-IG and OU-Normal stochastic processes, capturing seasonality, jumps, and mean reversion. Calibrated models to market data and simulated option prices via Monte Carlo.
